# إعراب الكلمات العربية

موقع تعليمي لإعراب كلمة في سياقها أو تحليل الجمل العربية كاملة. الواجهة مستضافة داخل GitHub Pages، وخدمة التحليل تعمل عبر Cloudflare Workers وتستدعي OpenAI Responses API من جهة الخادم.

## الملفات

- index.html: واجهة عربية RTL، اختيار تحليل كلمة/جملة، إدخال السياق، عرض النتيجة، النسخ والطباعة.
- worker.js: واجهة API، التحقق من الطلبات، CORS، التحقق من المخرجات المنظمة، ورسائل الأخطاء العربية.
- wrangler.toml: إعداد نشر Worker باسم arabic-irab-doha-api.

## المتطلبات والإعداد

1. أنشئ سرًا في إعدادات Worker باسم OPENAI_API_KEY يحتوي مفتاح OpenAI API فعليًا. لا تضع المفتاح في ملفات هذا المستودع أو في كود المتصفح.
2. اضبط المتغير ALLOWED_ORIGIN على https://ammaralomari29.github.io.
3. القيمة الافتراضية للنموذج هي gpt-5-mini (يدعم Responses API وStructured Outputs). يمكن تحديد OPENAI_MODEL كمتغير بيئة إذا أردت نموذجًا آخر متوافقًا.
4. انشر Worker من مجلد المشروع:
   npx wrangler deploy --config arabic-irab-doha/wrangler.toml
   أو انشر worker.js من لوحة Cloudflare Workers، مع إعداد المتغيرات والسر أعلاه.
5. انشر تحديث GitHub Pages. تتحقق الواجهة من Worker الحالي:
   https://arabic-irab-doha-api.ammaralomari29.workers.dev

## عقد الاستجابة

يرسل المتصفح { mode, text, context } إلى Worker. تعود النتيجة في { analysis: { summary, ambiguity_notes, items } }. عناصر items تشمل الكلمة، نوعها، موقعها، العلامة، نوع العلامة، الإعراب الكامل، الشرح، والضمائر واللواحق.

## حدود الحماية

يتحقق Worker من الأصل وحجم النص واللغة، ويضع حدًا أوليًا للطلبات لكل عنوان IP داخل ذاكرة العزل، ويخفي تفاصيل أخطاء المزود. حد الذاكرة هذا مؤقت وعلى مستوى العزل فقط، وليس حدًا موزعًا بين جميع مثيلات Cloudflare. قبل الإعلان العام واسع النطاق، أضف Cloudflare Rate Limiting أو Turnstile مع التحقق الخادمي. لا تسجل المدخلات أو المفاتيح.

## فحوص سريعة بعد الإعداد والنشر

- افتح / على Worker وتأكد من رسالة الخدمة.
- جرّب كلمة بلا سياق، وكلمة مع جملة، وجملة تامة، وتأكد من ظهور جميع الكلمات والتنبيهات.
- تحقق أن الأصل المسموح هو GitHub Pages، وأن المتصفح لا يرسل أو يستقبل مفتاح API.
- جرّب الطلب الفارغ والنص غير العربي وتأكد من ظهور رسالة مفهومة.
